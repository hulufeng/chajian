### MPU6050 六轴 IMU
MPU6050 用 I2C 输出三轴加速度 + 三轴陀螺仪，用于姿态、倾角、运动/跌倒检测：
```cpp
#include <Wire.h>
#include <MPU6050.h>
MPU6050 mpu;
int16_t ax,ay,az,gx,gy,gz;
void setup() {
  Serial.begin(115200); Wire.begin();
  mpu.initialize();
  Serial.println(mpu.testConnection() ? "connected" : "fail");
}
void loop() {
  mpu.getAcceleration(&ax,&ay,&az);
  mpu.getRotation(&gx,&gy,&gz);
  Serial.printf("a:%d,%d,%d g:%d,%d,%d\n",ax,ay,az,gx,gy,gz);
  delay(100);
}
```
要点：地址 0x68（AD0 拉高为 0x69）；静止判断可用加速度模长是否接近 1g；要得到稳定角度需对加速度/陀螺做互补或卡尔曼滤波（库如 MPU6050_DMP6 用硬件 DMP 输出 yaw/pitch/roll）；模块要水平固定、远离电机干扰。
