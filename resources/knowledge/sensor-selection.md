### 常用传感器选型对照
按测量目标选型号（接口 I2C/SPI/单总线/模拟）：

| 测量 | 入门 | 进阶 |
|---|---|---|
| 温湿度 | DHT11/DHT22（单总线） | SHT3x、AHT20（I2C，精度高） |
| 温湿度+气压 | BME280 | BME680（+气体） |
| 光照 | LDR（模拟） | BH1750、VEML7700（I2C lux） |
| 人体 | PIR（移动） | mmWave 毫米波（静止存在） |
| 姿态 | MPU6050（六轴） | LIS2DH/带 DMP |
| 距离 | HC-SR04（超声） | VL53L0X（激光 ToF） |
| 气体 | MQ-2/135（定性） | MH-Z19/SCD41（CO2 NDIR） |
| 颜色/手势 | — | APDS9960（I2C） |
| 角度 | 电位器（模拟） | AS5600（磁编码 I2C） |

选型原则：要数值/稳定优先 I2C 数字传感器；模拟量需标定且受噪声影响；注意供电（3.3/5V）与接口电平；多 I2C 设备注意地址冲突。
