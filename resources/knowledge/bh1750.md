### BH1750 数字光照度
BH1750 用 I2C 直接输出光照度（lux），比光敏电阻线性、无需校准，用于自动调光/照明：
```cpp
#include <Wire.h>
#include <BH1750.h>
BH1750 light;
void setup() {
  Serial.begin(115200); Wire.begin();
  light.begin(); // 地址 0x23(ADDR低) 或 0x5C
}
void loop() {
  Serial.printf("%.0f lx\n", light.readLightLevel());
  delay(500);
}
```
要点：量程约 1~65535 lux；ADDR 脚接 GND 是 0x23、接高是 0x5C；读数为 0 检查地址/接线；只需粗略光线可用模拟 LDR，要数值和一致性选 BH1750/VEML7700。
