### LCD1602 字符屏（I2C 版）
用 LiquidCrystal_I2C 库（库管理器搜 LiquidCrystal I2C）：
```cpp
#include <LiquidCrystal_I2C.h>
LiquidCrystal_I2C lcd(0x27, 16, 2);   // 地址 0x27，16列2行
void setup() { lcd.init(); lcd.backlight(); lcd.setCursor(0, 0); lcd.print("Hello"); lcd.setCursor(0, 1); lcd.print("ESP32!"); }
void loop() { lcd.setCursor(0, 1); lcd.print(millis() / 1000); }
```
接线：I2C 版只需 VCC/GND/SDA/SCL（同 I2C 总线，ESP32-C3: SDA=GPIO8, SCL=GPIO9）。
常见坑：地址可能 0x27 或 0x3F（I2C 扫描确认）；背光不亮查 backlight()/跳线；打印超 16 字会折行乱，先 setCursor 定位。
