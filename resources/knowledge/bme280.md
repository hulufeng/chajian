### BME280 温湿度气压传感器
BME280 用 I2C 一次读出温度、湿度、气压，可估算海拔/天气（BMP280 无湿度，BME680 多气体）：
```cpp
#include <Wire.h>
#include <Adafruit_BME280.h>
Adafruit_BME280 bme;
void setup() {
  Serial.begin(115200);
  if (!bme.begin(0x76)) Serial.println("BME280 not found"); // 地址 0x76/0x77
}
void loop() {
  Serial.printf("T=%.1fC H=%.1f%% P=%.1fhPa\n",
    bme.readTemperature(), bme.readHumidity(), bme.readPressure()/100.0F);
  delay(2000);
}
```
要点：找不到先扫 I2C 地址（0x76 或 0x77）；海拔用 `bme.readAltitude(seaLevelHPa)`；气压对天气/高度变化敏感，室内读数受通风影响；同类 SHT3x 只测温湿度但精度更高。
