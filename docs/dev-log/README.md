# 开发记录（dev-log）

这个目录是**项目的开发过程档案**，记录真实的设计取舍、踩过的坑、以及阶段性交接状态。
放进来而不是删掉，是因为这些内容对外部贡献者有参考价值——尤其是「为什么这么设计」和
「这里曾经错在哪」这两类信息，通常不会出现在代码注释里。
