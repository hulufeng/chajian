## 二、与 TrieCode / 豆包的关键差异

| 维度 | LabCode | TrieCode | 豆包 |
|---|---|---|---|
| 模型 | Qwen2.5-Coder-3B（本地 GGUF） | MiniMax M2.7（云端） | 豆包大模型 2.x（云端） |
| 联网 | ❌ 完全离线（隐私/免费/可用性） | ✅ 需联网 | ✅ 需联网 |
| 成本 | 0（本地推理） | 积分计费（如 1.68 积分/次） | 订阅制 |
| 工具调用 | **确定性路由**（意图检测→注入/代码块+应用到文件） | 模型自主调工具（16s/1工具） | Function Calling/MCP 强 |
| 多步自主任务（如 编译→烧录→改→再烧录 闭环） | ❌ 弱（3B 上限，工具循环仅限明确操作词） | 中 | ✅ 强（18h RTL 测试） |
| 工作可视化 | ✅ 「▶ 已工作 Ns」计时器+token 计量 | ✅ 16s+工具计数+积分条 | ✅ 任务过程展示 |
| 教学知识库 | ✅ 内置 40-60 条 ESP32 知识（可插件更新） | 无专门硬件知识库 | 私域知识库（需配置） |
| 冷启动 | 40-60s（首问，引擎加载 2GB 模型） | 秒级 | 秒级 |

## 三、LabCode 最终定位与结论

- **定位**：离线 ESP32 教学编程助手——10 项日常任务（生成/解释/修改/问答/多轮/组合/边界/调试/简洁/排查）全覆盖，3-5s 离线免费完成，带「应用到文件」「代码块复制」等确定性交互。
- **与 TrieCode/豆包的关系**：不是同赛道——TrieCode/豆包是"云端全能 Agent"（能动手、质量高、付费联网）；LabCode 是"离线教学基本盘 + 真实烧录闭环"，差异化=离线+免费+隐私+烧录。
- **商业化路径**：
  1. 本地 3B 守住教学/日常问答（已完成 10/10）；
  2. 云端模型网关（bluebubai.work，已就绪待配 Key）承接"多步自主任务"付费点（编译烧录全自动闭环）；
  3. 计时/token UI 已建信任感。
- **剩余差距（明确）**：① 多步自主工具编排（云端补位）；② 冷启动 40-60s（AI 面板展开预热，低优先）；③ 大上下文长文档处理（3B 上下文 8k，适合教学片段，长文档留云端）。
