## 1. 任务拆解

### T1 · UI diff 可视化升级（优先级最高，纯前端自包含）
- **现状**：`DiffBlock`（AiPanel.tsx:259）把 ```` ```diff ```` 块按行染色渲染在 `<pre>` 里。
- **目标**：整文件可视化 diff，对齐 TrieCode：
  - 行号栏（旧号 / 新号）
  - hunk 头（`@@ -a,b +c,d @@`）识别与展示
  - 增删统计徽标（`+N −M`）
  - 词级高亮（同一行的字符级差异，非整行染色）
  - 统一视图 / 并排视图切换
  - 长 diff 折叠（超过 N 行默认折叠，可展开）
- **做法**：新增独立组件 `src/renderer/src/components/DiffView.tsx`（解析 unified diff → 结构化 hunk；纯函数解析器可单测），
  `AiPanel.tsx` 的 `DiffBlock` 改为调用它。样式走 `main.css` 新 `.diff-*` 类，全部 `var(--token)`。
- **验证**：新增 `scripts/check-diff-view.mjs`（解析器单测：多 hunk / 无 hunk 头 / 词级 / 空行 / CRLF）；
  `scan-ui-crash` 无风险；tsc 双过。
- **风险**：低。不碰 IPC、不碰主进程。

### T2 · MCP 常用服务器一键预设（生态体验）
- **现状**：能加 MCP server，但要用户手填 `npx -y @modelcontextprotocol/...`。
- **目标**：MCP 页顶部加「常用服务器」预设卡片，一键填入 name/command/args；仍走**信任门控**（预设不自动信任）。
- **预设清单**（官方 MCP servers，均为 npx 包）：filesystem / fetch / git / memory / sqlite / sequential-thinking。
- **做法**：`SettingsModal.tsx` 新增 `MCP_PRESETS` 常量 + 预设行；点击 `setMcpDraft({name, command})`（与现有 add 流程共用）。
- **验证**：tsc 双过；`scan-ipc-handlers` 0 命中（不改通道）。
- **风险**：低。预设只是填串，用户仍须点「信任」。

### T3 · Anthropic 通道 + 长上下文放开（补齐「最大差距」）
- **现状**：`chatByok` / `aiChatStream` 的 BYOK 分支写死 OpenAI 格式 → Claude 预设点了必 404。
- **目标**：新增 Anthropic Messages API 适配（非流式 + 流式 SSE），使 BYOK 选 Claude 能真正跑通 function calling。
  - 端点：`{baseUrl}/messages`（baseUrl 为 `https://api.anthropic.com/v1`）
  - 头：`x-api-key` + `anthropic-version: 2023-06-01`（不用 Bearer）
  - body：`system` 抽离、`messages` 规整、`tools` → Anthropic `tools` 形状、`max_tokens` 必填
  - SSE：`content_block_delta`（text_delta / input_json_delta）→ 归一化为现有 `StreamChunk`
- **长上下文**：`read_file` 截断从硬编码 4000 改为按「当前通道窗口」取值（本地 8K → 4000；云端/BYOK → 16000），
  并在截断提示里说明原因。
- **做法**：`aiGateway.ts` 新增 `isAnthropic(baseUrl)` 判定 + `chatAnthropicByok` / `anthropicStream`；
  两条 BYOK 路径按 provider 分派。`engine/tools/index.ts` 的 `MAX_READ_CHARS` 提为按模型窗口函数。
- **验证**：新增 `scripts/check-anthropic-adapter.mjs`（起本地假 Anthropic server：非流式 + 流式 + tool_use 归一化）。
- **风险**：中。改 AI 主链路，必须 tsc 双过 + 现有 `check-cloud-official` / `sim-local-model` 回归。
