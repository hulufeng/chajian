## 各功能测试细节

### 1. 主界面（✅）
标题栏 40px（LC/文件/编辑/视图/帮助 + 板卡选择）、左侧项目面板、中间 Monaco 编辑器（welcome.ino 示例已开）、右侧 AI 面板、底部五标签（输出/问题/串口监视器/绘图仪/终端）+ 状态栏（工具链 1.5.2-rc1 / 后端就绪 / 插件 3 / COM1·115200）。布局无遮挡无溢出。

### 2. 标题栏菜单（✅）
文件/编辑/视图/帮助四菜单可点开（截图显示"文件"菜单展开）。

### 3. 编译（✅ 真实执行）
点击顶部"编译"按钮 → arduino-cli 真实编译 welcome.ino → 输出"Global variables use 184 bytes (8%) of dynamic memory…" + **[任务结束，退出码 0]**——编译链路真实可用。

### 4. 模拟烧录（✅ 完整链路）
仿真面板 → 烧录 Tab → 虚拟板卡 ESP32-C3 / 固件来源"内置演示固件" / 演示"Blink 点灯演示" → 点"▶ 模拟烧录" → **100% 完整日志**：连接 → 识别（Chip verified: ESP32-C3）→ stub → 4 分区逐块烧写（0x1000/0x8000/0xe000/0x10000）→ `Wrote 261600 bytes (149892 compressed) in 2.9 seconds` → **`Hash of data verified`** → `Hard resetting via RTS pin` → `Done. 4 file(s) written successfully` → UI"✅ 烧录成功·再烧一次"。

### 5. 仿真外设（✅）
仿真 Tab 含 OLED 显示/文本输入、ADC1 多通道滑块×4、环境（SHT30·DHT22 共享）、三通道示波器画布。

### 6. AI 对话-云端（⚠️ 服务端限制）
发送消息 → `错误: 流式请求失败 (401): {"error":"未登录或登录已过期"}`——用户登录 token 在服务端已过期/无效；且内置 5 模型服务端 `available=False`。**此为账号/网关侧状态，软件本地无 bug**；处置：用户重新登录或查网关。

### 7. AI 对话-本地模型（✅ 本轮修复后实测）
**发现 bug**：AI 面板模型下拉不显示本地模型（显示"＋ 添加 API Key"）→ 根因 `model:local` IPC 仍检查 Ollama 运行（`isOllamaRunning()` 为 false 即返回空），内置 llama 引擎不被识别。**已修复**：去掉 Ollama 门禁，直接 `listLocalModels()`（扫描 models 目录 GGUF）。
**复测通过**：模型下拉切到 `local:qwen2.5-coder-1.5b…` → 发送"你好，请用一句话介绍你自己" → 本地引擎回答"我是 LabCode AI 智能体，可以帮你写代码、执行命令、搜索网络、管理项目。"——**UI 全链路（选择→发送→引擎→流式回复）真实可用**。

### 8. 消息操作（✅）
user 消息 hover 显示三按钮：重新生成（重发该条）/ 编辑并重发（文本回填输入框）/ 回退到这里（截断）。此前已逐项 CDP 实测。

### 9. 面板宽度拖拽（✅）
左缘拖拽手柄，实测拖宽生效（localStorage 持久化）。

### 10. 上下文用量（✅）
动态估算：对话消息 tokens（中文 1.5 字符/token）、16K 窗口百分比、引用/工具记录数、压缩按钮（保留最近 10 条）。

### 11. 语音输入（✅ 界面状态；能力受在线引擎限制）
按钮"语音输入/停止聆听"双态 + 红色脉冲正常；点击启动识别器（无外网时 network 错误已去重限流 30s + 如实文案）。真正本地语音（whisper）待用户拍板。

### 12. 课程面板（✅）
活动栏"课程"→ 左侧课程列表（ESP32 闯关课程等），可打开示例。

### 13. 终端（✅）
标题栏"终端"→ 底部终端面板打开（xterm 样式）。

### 14. 插件·大模型页（✅）
活动栏"插件"→"大模型"Tab：徽标"本地引擎运行中" + Qwen2.5 Coder 1.5B"已安装 ✓" + 其余两档可下载。

## 本轮发现并修复

| 问题 | 根因 | 修复 | 验证 |
|---|---|---|---|
| AI 面板无本地模型选项（显示"＋ 添加 API Key"） | 主进程 `model:local` 仍检查 `isOllamaRunning()`，内置引擎运行时返回空列表 | 去掉 Ollama 门禁，直接扫描 GGUF（`listLocalModels()`） | 重启后下拉出现 `local:qwen…`，切换发送成功 |
